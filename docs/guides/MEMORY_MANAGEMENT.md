# 记忆管理

长期记忆使用 `state/memory.sqlite`，通过工作线程读写。旧 `activeTopics`、`pendingThoughts`、`userImpressions` 和 `qq_memory_query/append/remove/clear` 接口保留。旧工具的 clear 不等于长期记忆的永久清除。

## 启用

1. 使用支持 `node:sqlite` 的 Node 22.13+；本次验证使用 Node 22.23.4。
2. 安装依赖，按照项目已有的 DSH 安装流程更新预设，运行 `node scripts/build-agent-preset-patches.mjs` 生成补丁。生成器包含新增 `qq-memory` 预设，需要重启 DSH 使预设生效。
3. 打开现有控制台的“记忆管理 → 策略”，启用“仅整理观察”。二代仿真收到经过准入的消息后建立账号与会话范围，采集完整文本。
4. 检查整理结果、来源和待处理项，在策略中选择“当前会话”，仅对目标群/私聊切换“整理并注入聊天”。全局关闭会覆盖所有会话；观察模式也禁止聊天模型通过长期记忆工具绕过开关。不需要另建管理网站。

在控制台保存的策略保存在 SQLite，重启继续生效；初始配置可写入 `config.json` 的 `memory` 节点。数据库位置只能通过启动配置修改。

## 日常使用

- 记忆库按类型、状态和正文筛选；编辑生成新版本，冲突返回 409 并保留草稿。
- 管理员录入或修改会生成相应来源记录；原始消息证据只读。
- 正文支持安全的标题、段落预览，`[[记忆ID]]` 建立链接。关系页可查看反向链接和一跳图。人物按 QQ ID 区分，主题用于组织记忆。
- 历史恢复生成新版本，不覆盖旧版本。合并先预览版本和范围，再提交；证据和历史保留。
- 待处理项可以确认、绑定 QQ 身份、解除来源、保留争议或忽略。
- 召回预览不会写入投递回执。普通召回默认最多6条、800预算，深入查询3000预算。缺少对应 tokenizer 时以 UTF-8 字节作保守上界。
- `qq_memory_recall/evidence/propose` 只能访问调用者会话。模型提案进入待审核，不能直接覆盖管理员记录。

## 整理与消耗

同一账号的所有群和私聊共享每日普通整理4次、反思1次额度。重试、手动整理和重建同样计入，未知 usage 不返还额度。超长来源按字符边界分批，原文完整保存，游标和候选同事务提交。

整理使用独立、无工具的 `qq-memory` 预设，每批新建会话。预设将 AgentOptions.maxTokens 固定为1000，低于普通整理默认1500上限；策略设置低于1000时明确拒绝调用。实际 DSH 请求用量仍由原账本处理，没有新增逐步 token 明细。未安装预设、适配器不兼容或请求失败会显示失败状态。

## 清除边界

永久清除先展示影响闭包：同来源和知识依赖可能扩展到其他记忆。确认后取消相关后台任务、清除活动数据库中的来源和派生记录、清理索引与视图，并退役该 QQ 会话、清空无法逐项追溯的旧工作记忆、撤销旧会话令牌。清除期间暂停写入与发送，持久屏障在重启后恢复；已清除的平台消息通过墓碑阻止重放。

远程 DSH 日志、QQ 服务端历史以及人工备份不在活动记忆数据库的清除保证内。控制台不会把这些范围显示为已确认清除。恢复旧备份需要同时保留最新墓碑，不能用旧备份覆盖后直接上线。

## 当前能力与验证范围

- 默认中文 FTS5 检索。向量接口预留；未安装本地向量适配器时明确显示不可用，不会调用收费 embedding。
- 当前使用 DSH 原生压缩。没有验证运行实例的 QQ 摘要扩展时，保持 visibility unknown，并允许必要记忆重新召回；不改变原生压缩阈值。
- Obsidian 风格的库、链接与管理界面已在控制台中提供。真实 Obsidian vault 双向同步仍是可选后续模块，本次不自动读写个人库。
- `npm run test:memory` 使用临时数据库和离线 QQ/DSH fixture。浏览器测试沿用现有项目方式，通过 `PLAYWRIGHT_MODULE` 和 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定 Playwright 与 Chromium；不会发送真实 QQ 消息。
- 上线前需要在目标 DSH 实例确认 `qq-memory` 预设已注册且输出限制生效；离线测试不等于真实账号验证。

本次离线验证：记忆测试15/15、原 token 协议与账本测试通过。原审计33/35，既有失败为缺失的 `VOICE.md` 和 DSH 工具名单检查；原控制台21/23，旧提交同样出现请求基线不匹配与走势图异步断言失败。这些历史失败未通过放宽断言来掩盖。
